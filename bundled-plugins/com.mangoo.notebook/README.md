# Mangoo 笔记库

在插件管理器中启用「笔记库」，并授予资料库数据权限。打开主窗口左上角的库选择器，选择「创建笔记库…」，填写名称和数据库位置。笔记库与媒体库共用切换器。停用插件会关闭当前笔记库，再次启用后可以重新打开。

## 目录与标签页

左栏可以新建多级文件夹。选中文件夹后新建或导入笔记，内容进入该目录。导入整个文件夹会保留笔记的子目录层次，并复用已存在的同名目录。把笔记或文件夹拖到目标文件夹即可移动，使用键盘时也可以选择「移动到文件夹」。F2 重命名文件夹，左右方向键展开或收起。标题栏的定位按钮会展开目录并选中当前笔记，正文上方的路径可以定位到某一级文件夹。拖动左栏右边缘可调节宽度，布局和宽度与图片库共用。

从左栏打开笔记，标签会出现在窗口标题栏中间。左栏标题和目录共用图片库的玻璃面板。标题栏依次提供库切换、插件、设置、定位和侧栏开关，通知和窗口控件位于右侧。再次打开同一篇会定位到已有标签。标签放不下时，可在标签上滚动滚轮查看其余笔记。拖动标签可调整顺序，中键可关闭标签。Ctrl+Tab 和 Ctrl+Shift+Tab 循环切换，Ctrl+W 关闭当前标签。聚焦标签后，Ctrl+Shift+PageUp 或 PageDown 可左右调整其位置。关闭标签会保留笔记。刷新时，每个窗口分别恢复该库的标签顺序和当前篇目。

在 Markdown 编辑工具栏点击「文档大纲」可跳到相应标题。宽窗口会并排显示大纲，窄窗口将它收在正文上方。源码视图提供行号，底部显示光标位置。

## 设置与单篇样式

在主窗口打开「设置 → 笔记」。Markdown 可以默认进入实时写作或源码，HTML 可以默认进入源码、对照或预览。这里也可以设置文档大纲、源码自动换行，以及正文、各级标题、代码、引用、表格和图片等元素的默认样式。设置会立即应用到本机各笔记库，手动切换过视图的标签页会保留自己的选择。

单篇笔记需要不同排版时，在编辑工具栏打开「元素样式」。修改的属性会随这篇笔记保存和同步，其他属性继续采用本机默认值。「恢复此元素默认样式」让该元素重新跟随本机设置。

## 写作和阅读

- **Markdown** 支持在原处排版标题、强调、引用、列表、任务、表格、代码和图片。把光标移入标记即可编辑，也可以切换到源码。「元素样式」按笔记保存，支持单独设置各级标题、正文、引用、代码、图片等元素，也支持输入字体、间距、颜色和边框的 CSS 声明。
- **HTML** 支持源码、对照及页面预览。单文件网页可包含内联 CSS 和 JavaScript。在页面上打开交互开关后，脚本可以操作该预览页面。预览使用隔离的 iframe。需要联网、登录或远程框架的网页应先准备离线版本。
- **附件** 可通过编辑器的附件按钮插入，也可以拖入图片、粘贴截图或带本地图像数据的富文本。正文保存稳定的附件标识，图片与原件归属于当前笔记。点击文档预览的下载按钮可取回原文件。
- **导入** 可选择多个文件或目录。Markdown、HTML 和纯文本会成为可编辑的笔记。导入引用本地图片的笔记时，同时选中图片，或选取包含二者的文件夹以保留相对路径。HTML 导入也会收集一并选入的本地样式表和脚本。行内样式和样式表里的背景图按引用文件的相对路径收集。只含远端地址的资源会提示补充原件。
- **文档笔记** 支持将 Word、Excel、PowerPoint、OpenDocument、PDF、EPUB 等文件作为单独笔记打开，或插入已有笔记。Office 采用本地内容阅读视图，可以阅读正文、表格或幻灯片。PDF 支持翻页，EPUB 按书脊顺序阅读章节。「编辑批注」可在原件旁继续书写，原文件始终可以下载。
- **查找与保存** 在左侧输入时按标题筛选，回车搜索标题和正文。Ctrl+K 定位笔记库搜索。编辑器内 Ctrl+F 查找当前文档。输入会自动保存，Ctrl+S 可立即保存。版本冲突时可选择保留本机草稿或使用库中版本。工具栏可导出 Markdown 或 HTML，含附件的笔记导出为 ZIP，正文使用包内相对路径，ZIP 可以重新导入并恢复元素样式。

## 同步与容量

通过主程序的资料库同步设置绑定笔记库。正文、元素样式、文档原件和图片都使用同一套同步提供程序。新建库默认为本地模式。恢复远程库时会保留笔记库类型。正文和附件按需分块保存，笔记和便携 ZIP 均无预设的单篇或单文件大小上限。临时文件、库和同步副本需要可用磁盘空间。编辑器打开正文、阅读器解析原件、同步引擎重建目录时仍受设备内存和运行时能力影响。同步中的附件在分块到齐并校验后可打开。EPUB 预览只解压实际用到的章节、目录和插图，单项解压后最多 32 MiB，合计最多 160 MiB。超过预览预算时可下载完整原件。

仓库默认打包开发用同步提供程序。实际使用 OneDrive 需要为主程序选择独立构建的 OneDrive Sync 插件，再在其界面中登录、绑定资料库。笔记库沿用该绑定。详见[同步插件接入说明](../../docs/onedrive-extraction.md)。

## 实现与验证

插件入口是同目录下的 `plugin.template.json`，宿主能力是 `notebook.v1`。Web 工作区通过 `@mangoo/web/plugin-host` 和 `@mangoo/core-client` 访问宿主。Core 在活动库、插件状态和资料库权限的约束下处理笔记请求。使用宿主已有的授权和绑定界面。

- `npm test` 运行项目回归套件。
- 在完成开发版 Core、内置插件、Desktop 和 Web 构建后，运行 `node tools/checks/notebook-desktop.mjs`。在 Windows 发行包上执行相同验收时追加 `--packaged`。验收使用独立临时目录，截图保存在 `.tmp/notebook-desktop/` 的当次运行目录中。
- 要复验文档阅读器，可在安装了 Microsoft Office 的 Windows 机器上运行 `powershell -STA -File tools/checks/notebook-reader-office-fixtures.ps1 -OutputDirectory .tmp/reader-office` 生成 Word、Excel 和 PowerPoint 样本，再运行 `node tools/checks/notebook-readers.mjs .tmp/reader-office`。已有样本可以直接复用。此检查同时验证开发和生产前端中的旧版及新版 Office 文档、中文 PDF 翻页和 EPUB 章节切换。
